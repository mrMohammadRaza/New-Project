# AgriFlow Mobile (Expo Go)

React Native & Expo mobile app for AgriFlow (SIH20676).

## Running with Expo Go

1. Install dependencies:
```bash
cd mobile
npm install
```

2. Start Expo Metro bundler:
```bash
npx expo start --tunnel
```
*(or `npx expo start` if your phone is on the same local Wi-Fi network)*

3. A large QR Code will be printed in your terminal and opened at `http://localhost:8081`.
4. Open the **Expo Go** app on your iPhone or Android phone, and scan the QR code to run AgriFlow instantly!
